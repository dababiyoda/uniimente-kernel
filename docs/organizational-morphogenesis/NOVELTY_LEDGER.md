# Novelty Ledger

This ledger prevents ordinary orchestration components from being mislabeled as
invention.

| Element | Origin | Material mutation | New combined capability | Evidence status |
|---|---|---|---|---|
| Durable workflow | Temporal-style explicit state plus Kernel `DurableWorkflow` | Mission-bound, topology-comparative, reconciliation-first, independent closure | Same mission can be replayed under competing organizations without a second runtime | Semantics only |
| Task queue | At-least-once queues/JetStream | One-task WorkerLease, no authority inheritance, reserved resources, uncertain-effect block | Replaceable workers without permanent agent power | Deferred Phase 2 |
| Supervision | OTP restart trees | Lease supervision, static degradation, evaluator separation, state-transfer proof | Failure recovery without institutional hierarchy | Deferred Phase 2 |
| Incident command | Mission-bounded temporary organization | Machine contracts, enumerated coordinator rights, symmetric dissolution, do-not-instantiate | Organization can be formed and dissolved around one authorized mission | Semantics only |
| Formal dissent | NASA/high-reliability practice | Hard closure metric, separate capacity, suppression kill, loss preservation | Evaluation remains institutionally independent from synthesis | Contracted; not executed |
| Quorum | Immune/microbial thresholds | Proposal-only, correlation discount, rollback/resource proof, no-change default | Evidence-triggered reconfiguration without self-authorization | Deferred Phase 3 |
| Stigmergy | Collective local traces | Typed Event Spine, eligibility gate, amplification price, central synthesis | Broad pull-based research without giant shared context | Deferred/new experiment required |
| Apoptosis | Controlled biological dissolution | Independent closure, obligation reconciliation, authority non-return, loser retention | Temporary institution ends without bureaucracy or amnesia | Contracted; not executed |
| OMNIMORPH | Existing capability/organ composition | Capability + organizational genome, static/do-nothing competitors, executed-only validation, loser memory | Mission asks what institution should exist, not merely which worker acts | Hypothesis |
| TopologyEpisode corpus | Provenance plus comparative experimentation | Geometry binding, causal failure/cost/dissent record, preservation disposition | Verified organizational history can improve later design decisions | Schema only; corpus empty |

## What is not novel

- centralized, decentralized and hierarchical diagrams;
- master-agent plus workers/tools;
- a task queue, scheduler, actor system or workflow engine by itself;
- biological vocabulary;
- an LLM choosing “hybrid” from prose;
- a model-generated scorecard without executed episodes.

## Novelty test

The thesis survives only if one bounded mission can be compiled into materially
different organizations, run through the same canonical substrate, compared
under identical constraints, and converted into reusable evidence without any
authority expansion. Until that execution exists, novelty is a design claim,
not a proven capability.
