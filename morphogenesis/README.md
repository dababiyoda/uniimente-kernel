# `morphogenesis/` — target-state control lineage

This package is preserved because it contains useful bounded set-point, observation, action-ranking, and descendant-proposal mechanisms.

It is **not the canonical definition of morphogenesis for UNIIMENTE**.

## Founder correction

See `docs/FOUNDER_EFFECT_COMPILER.md` and `docs/intent/INTENT-0029-effect-not-metaphor.md`.

Canonical rule:

> **Preserve the effect. Do not literalize the metaphor.**

Canonical UNIIMENTE morphogenesis means **functional capability formation or reconfiguration in response to a verified discrepancy or CapabilityDeficit**.

This may be achieved by:

- using an existing capability;
- composing capabilities;
- adopting/adapting open source;
- using an API, plugin, service, model, or authorized computer-use environment;
- generating a small utility;
- commissioning a coding agent;
- forming a temporary specialist team;
- replacing a failed implementation;
- or building new architecture when nothing simpler satisfies the effect.

The classes in this package are one historical/current control mechanism. Their vocabulary—set-points, descendants, replication—does not require the wider institution to imitate developmental biology.

## Interpretation boundary

Do not use this package name as evidence that:

- UNIIMENTE must contain digital cells or tissues;
- local-rule development is required;
- descendant formation is required for every mission;
- organizational self-assembly is morphogenesis;
- biological resemblance proves adaptive capability.

Use these mechanisms only where they solve a named target effect better than the alternatives.

The package continues to fail closed and does not gain new authority from this clarification.
