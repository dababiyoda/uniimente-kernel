## Faithful founder statement

The founder intended biological, institutional, and science-fiction concepts as metaphors and mechanism sources. The desired **underlying capability and effect are literal engineering targets; the metaphor's surface form is not.**

When Alfonso expresses an ambitious or apparently impossible target, contributors must not respond by either:

1. reproducing the metaphor literally in software; or
2. shrinking the aspiration to whatever today's code already does.

Instead they must determine the desired observable effect and resourcefully produce the strongest lawful, truthful, technically real mechanism available.

This includes aggressively considering:

- existing UNIIMENTE capabilities;
- commodity software;
- open-source repositories;
- APIs and services;
- plugins/connectors;
- computer-use environments;
- external coding agents;
- model/tool combinations;
- small generated utilities;
- temporary specialist teams;
- mutated/recombined mechanisms;
- new architecture only when simpler mechanisms are insufficient.

## Canonical morphogenesis meaning

Within UNIIMENTE, morphogenesis means **functional capability formation or reconfiguration in response to a verified discrepancy or CapabilityDeficit.**

A successful morphogenetic response may simply be:

- attach an existing tool;
- adapt an open-source project;
- compose existing capabilities;
- commission a coding agent;
- build a narrow utility;
- create a temporary team;
- restore a lost function with another implementation;
- package a repeatedly useful function as an organ;
- or decide that the simplest existing implementation remains superior.

It does not require biological simulation, digital tissues, local cellular rules, decentralized topology, or dynamically generated organizations.
