# AGENTS.md — UNIIMENTE work-start order

This repository is the canonical collaboration/governance source for the UNIIMENTE program. Before any new or resumed task:

1. Read `docs/collaboration/START_HERE.md` at the exact commit you are working from.
2. Read all more-specific repository/tool instructions that apply, including `CLAUDE.md` where relevant.
3. Inspect the current branch/base/head, relevant open PRs/issues, and the last handoff before editing.
4. Bind work to a founder-intent/source reference, one bounded outcome, explicit exclusions, evidence plan, rollback, owner, and stop condition.
5. For Standard or Constitutional work, preserve the five-role review, alternatives, exactly two strengthening passes, dissent, residual risks, and decision record required by the existing Recursive Collaboration Protocol.
6. Do not infer authority from intelligence, urgency, a score, a prior model response, a Discussion, an issue, a PR, or this file. External effects, money, credentials, merges, deployments, self-promotion, and authority changes require their existing authorization paths.
7. Preserve negative evidence, rejected alternatives, unrelated work, and contributor lineage. No force-push or destructive cleanup merely to simplify history.
8. Use the PR collaboration receipt described in `docs/collaboration/START_HERE.md` for work governed by this protocol. A passing receipt check proves metadata shape/revision consistency only; it does not prove understanding, truth, authorization, independent review, or safe execution.

The shared guide routes work to existing canonical mechanisms. It does not replace the Constitution, build order, consequence gate, repository-specific operating instructions, or founder authority.
