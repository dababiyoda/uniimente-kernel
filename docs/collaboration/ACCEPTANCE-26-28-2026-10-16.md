### What each kind of hosted evidence proves

- **The mutation response**, meaning the service's answer to the call, is the service's own claim. GREG never
  closes a mission on it.
- **A read-after-write through the same service** shows the service's resulting state. Example: a page on the
  service's own host. It is not independent corroboration.
- **Independent corroboration** needs an observation path that does not depend on the service's own report. GREG
  cannot prove a different host is independent, so it labels such a page "not proven independent".

Today a hosted mission closes on GREG's own render of a page you name, and each proposal says which of the two
render kinds it is. #28's written acceptance criteria require reachability only through identity, authority and
the Gate, plus swappable providers; they do not require independent corroboration of remote effects.

**Open decision (yours):** for a hosted change that no page shows, may a mission close on an authenticated read
through the same service's own read tool, labelled as read-after-write? Until you decide, GREG asks for a page
instead.
