## Negative evidence retained

- **Orphaned worker (fixed).** The first SIGKILL left the Claude Code worker running under PID 1; it edited the
  private clone (uncollected, never committed). Fix: workers start in their own session with
  `PR_SET_PDEATHSIG=SIGKILL` (Linux); regression `test_a_worker_dies_with_its_body`; mutation removing the
  signal makes it fail. macOS has no parent-death signal (stated limit).
- **Spend accounting is conservative, not exact.** The mission books the signed cap per action ($3.00) rather
  than the provider-reported spend; the interrupted run's actual spend was not observable and is not booked.
- **PyPI search is unreachable to a headless browser** (Client Challenge). GREG records and routes around
  it; it never solves challenges.
- **TLS interception in this container.** The browser imports the operator-configured CA bundle
  (`GREG_BROWSER_TRUST_BUNDLE`) into each disposable profile; verification stays on.
- **Isolation limits.** The worker is confined by its tool allow-list, working directory and budget flag, not
  by an OS sandbox, and needs its provider's network. Chromium runs `--no-sandbox` as root here
  (`os_sandboxed: false` in the trace).
- **Reviewer dissent on `00b9fe7`.** `computer_use_ready()` requires certutil, which `browser.session` only needs
  when a trust bundle is configured; it can report a false "not ready". Kept as produced; dissent recorded on the PR.
