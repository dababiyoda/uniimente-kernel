# P8 cycle 6 canary: pre-registration (2026-10-21)

**What this is:** the canary that cycle 6's proposal names before any adoption, run as a measurement. It changes no
configuration, no genome version and no routing. Adopting the proposal stays the founder's decision; this run only
informs it.

**Status:** written and committed before any canary instance is generated. The script is
`scripts/p8_cr6_canary.py`; its rules are `decide()`, tested in `tests/unit/test_p8_cr6_canary.py`.

## What is fixed

| Item | Value |
|---|---|
| Seeds | 8300-8539 (240 instances), `evolution.CR_CANARY_SEEDS["cycle-6"]`: inside P8's reserved range, never generated by any freeze, cycle, admission run or pilot, and excluded from every later cycle's split by `cr_split_seeds` |
| Arms | the incumbent `CR_DEFAULT_CONFIG` (`cfg-111751096c0d`); the proposed configuration read from `cycle-cr-6.json` (`cfg-4398ea71018f`); random restart (the target's baseline and admission competitor) |
| Loss | the cycle's: `SealedEvaluator.losses` over `constraint_release_score`, on the output of the sandbox's method run in-process (confinement does not change outputs) |
| Stress | the cycle's `_cr_stress` on the canary items (lean budget 16; validation cut to four), every answer verified |
| Run | once, from a clean tree at the commit that adds this file, pinned to one core; the output is never overwritten |

| **CANARY_PASSES_BUT_RANDOM_RESTART_IS_BETTER** | as above, and random restart beats the proposal (one-sided sign test p < 0.05 and lower mean loss) |

Also reported, not decision inputs: random restart against the incumbent, and mean losses by instance subregion.

## Prediction (not part of the rule)

- **The proposal will beat the incumbent.** Cycle 6's held-out result (105-73, mean loss 29.6% lower) and cycle 5's
  pilot pool (`p_restart` 0.75-1.0 configurations beat the incumbent on 300 fresh items) both point that way.
- **Random restart against the proposal is uncertain.** Cycle 6 measured 89-80 for random restart with a lower mean,
  which was not significant. A significant random-restart win here would say the adoption question should be
  "replace the evolutionary search with random restart", not "adopt `p_restart` 0.807".

## What each verdict changes

Nothing is applied by any verdict. The canary result is added to the founder's adoption decision. If adopted, the
genome's version and pin bump, and a formal re-admission on fresh admission seeds follows, as the proposal states.
