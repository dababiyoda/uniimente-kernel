# affect/

Functional affect *policy*: explicit, bounded machine control states that steer
attention, verification, urgency and escalation. Not consciousness or
personality.

| File | Defines |
|---|---|
| `affect-policy.yaml` | the control states, their triggers, ceilings and decay |
| `identity-coherence.yaml` | the identity-homeostasis signal (mission vs. belief vs. action vs. outcome) |
| `pathological-state-tests.yaml` | specifications proving affect cannot become a capture vector |

**Implemented by:** `memory/affect.py`. No affect state may change facts, create
evidence, raise authority, override law, resist shutdown, or authorize an
irreversible action.
