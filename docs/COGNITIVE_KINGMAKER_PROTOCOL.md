# Cognitive Kingmaker Protocol

## Status

**Proposal-only cognitive routing subsystem.**

This subsystem does not call a model, store provider credentials, deploy code, contact anyone, move money, or authorize an external effect. It determines which measured cognitive provider should attack which bounded problem and emits a costed routing proposal.

## Decision

UNIIMENTE will not appoint one model as its universal mind.

The operating pattern is:

```text
Alfonso
  establishes mission, corrections, and reserved authority
        |
        v
Founder-Intent Governor
  compresses the exact problem and protects doctrine
        |
        v
Novelty Architect
  searches beyond the current architecture
        |
        v
Institutional Compiler
  converts surviving mechanisms into contracts and tests
        |
        v
Independent Adversary and Evidence Auditor
  attack claims and define external verification
        |
        v
Alfonso and the Kernel
  authorize or refuse any consequential action
```

The present intended specialization is:

- **OpenAI-based founder-intent governor and institutional compiler:** preserve the accumulated project intention, detect architectural drift, route the correct problem, and integrate discoveries into the Kernel.
- **Claude Opus 5 novelty architect:** attack unfamiliar, open-ended, paradigm-level problems where non-obvious mechanism discovery is the dominant need.
- **Independent adversarial model:** challenge the lead architecture rather than echoing it.
- **Deterministic Kernel and external evidence:** determine permission and truth of outcome.

The code does not hard-code permanent vendor supremacy. Provider profiles contain local calibration scores and evidence references. Opus receives the novelty role only when it has the strongest measured novelty score among models that satisfy the request's capability requirements.

## Why this is one intelligence

The models do not merge weights or hidden reasoning. They become one operational intelligence because they share:

1. one founder-intent reference;
2. one protected invariant set;
3. one typed routing decision;
4. one causal memory and event spine;
5. one consequence boundary;
6. one externally verified learning loop.

The institution persists when any model is replaced. A model is a cognitive organelle, not UNIIMENTE's identity.

## Roles

### Founder-Intent Governor

- retrieves the minimum relevant doctrine and prior decisions;
- states the real bottleneck and unresolved contradiction;
- prevents a specialist model from solving the wrong problem brilliantly;
- preserves corrections, prohibitions, dissent, and commercial purpose.

### Novelty Architect

- receives an `InventionPacket` rather than the whole project history;
- generates at least five materially different architectures;
- must include a rejection of the current paradigm;
- must import one mechanism from an unrelated discipline;
- must include radical simplification, conventional software, and do-nothing routes;
- must state the strongest failure mode, hidden assumption, cheaper competitor, disconfirming experiment, and kill condition.

### Institutional Compiler

- extracts mechanism-level contributions;
- rejects vocabulary without executable semantics;
- produces state variables, interfaces, authority envelopes, tests, recovery paths, and repository placement;
- preserves rejected branches and revival evidence.

### Adversarial Reviewer

- must be independent from the lead novelty model when dissent is required;
- attacks the architecture before implementation;
- preserves the strongest minority objection;
- cannot authorize promotion.

### Evidence Auditor

- distinguishes source, claim, inference, simulation, receipt, and externally verified outcome;
- treats model output as hypothesis, never evidence by itself;
- defines the proof required to close the loop.

## Routing rules

```text
Known repetitive work
  -> deterministic code or inexpensive model

Known difficult implementation work
  -> implementation specialist

Unknown problem with an unclear solution space
  -> highest calibrated novelty model, currently intended to be Opus 5

High-consequence disagreement
  -> independent adversary plus evidence auditor

Any external consequence
  -> existing identity, authority, policy, evidence, budget,
     commit-time revalidation, Consequence Gate, receipt, and outcome path
```

## Cost doctrine

The expensive model is activated only at high-leverage uncertainty points. Every route estimates token cost before any invocation. If the required cognitive council exceeds the request budget, the router refuses rather than silently removing dissent or evidence review.

The governing metric is not tokens consumed. It is:

> **Novelty Conversion Rate:** the percentage of non-obvious mechanisms that survive founder-intent review, adversarial testing, implementation, and external comparison against the best conventional alternative.

A second economic metric is:

> **Cognitive cost per Clean Verified Outcome.**

## Invariants

1. Model identity never becomes institutional identity.
2. Model output is never evidence by itself.
3. A routing decision grants no capability or authority.
4. Every route output remains `PROPOSED_NOT_EXECUTED`.
5. External action remains structurally outside this subsystem.
6. High-consequence work requires human ratification.
7. Independent dissent cannot be simulated by the lead model reviewing itself.
8. Budget pressure cannot silently remove required safety roles.
9. Provider calibration must carry an evidence reference.
10. Alfonso remains the reserved constitutional authority.

## Files

- `cognition/kingmaker.py`: deterministic role selection, cost estimation, refusals, and invention-packet compilation.
- `contracts/cognitive-routing-decision.schema.json`: machine-readable proposal-only routing contract.
- `contracts/invention-packet.schema.json`: machine-readable novelty assignment contract.
- `tests/unit/test_cognitive_kingmaker.py`: adversarial and acceptance tests.

## Non-claims

This subsystem does not establish that Opus 5 is universally superior, that any benchmark measures general intelligence completely, or that UNIIMENTE has become one conscious mind. It implements a replaceable, evidence-calibrated division of cognitive labor under one persistent institution.
