# UNIIMENTE Foundry

The package contains two bounded institutional foundries with different jobs.

## 1. Evidence-Governed Media Foundry

Build ratifiable synthetic media companies around evidence-governed Territory Graphs, owned relationships, useful actions, products, correction duties, and Gate-only publishing.

## 2. Asymmetric Advantage Foundry

Convert a Phase Zero qualified opportunity into:

1. eleven preserved strategy routes;
2. a selected Advantage Architecture;
3. an eight-sided tribunal report covering four control super-nodes;
4. a dependency-aware, non-executing Composition Plan using the 55-technology arsenal;
5. an OMNIMORPH Organ Manifest and simulation;
6. an activation request that still requires human ratification and the canonical Consequence Gate;
7. a sealed Advantage Genome only after a clean paid, accepted, externally verified, reconciled outcome.

A Composition Plan is not a Genome. An Organ Manifest is not activation. A Gate receipt is not customer success. A payment without accepted external outcome is false closure.

## Buildability contract

- **Existing mechanism:** Phase Zero adapters, Territory Graph, 55-technology arsenal, Capability Genome Registry, hash-bound Ratifier, Spider-Web Tribunal, Consequence Gate, Evidence Ledger, Business Foundry, and Whole-Body Closure Controller.
- **Defined interface:** `TerritoryGraph`, `MediaCompanyCharter`, `CompanyFoundry`, `DistributionLoop`, `opportunity_from_canonical`, `AdvantageFoundry`, `SpiderWebTribunal`, `FoundryComposer`, and `FoundryPipeline`.
- **Bounded authority:** agents draft and rank; humans ratify; every external effect crosses the Gate; metrics, model consensus, tribunal output, plans, and manifests never create authority.
- **Available dependencies:** canonical Kernel contracts, policy, identity, provenance, Capability Genomes, registered technology status, Business Foundry receipts, and approved platform adapters.
- **Security model:** synthetic disclosure; no purchased metrics, outrage optimization, vulnerable-attention exploitation, fear-based retention, self-ratification, raw-model intake, changed-content replay, target-architecture activation, arbitrary receipt substitution, or hidden external incidents.
- **Failure modes:** invalid graph, weak or stale evidence, retired node, unratified or edited charter, incomplete governing transaction, fewer than eleven routes, missing tribunal lens or super-node, dependency conflict, partial/target technology, failed simulation, expired ratification, mismatched Gate receipt, dirty external outcome, or duplicate Genome version.
- **Acceptance tests:** rooted DAG and one owned exit; full route tournament; eight tribunal lenses; four super-nodes; dependency and detachment order; plan identity; capability and budget envelopes; human ratification; exact Gate receipt; false-closure detection; clean external sealing; correction, retirement, and restart recovery.
- **Recovery path:** suspend or reject the affected stage, preserve negative evidence, return to the nearest verified state, reconfigure the architecture or plan, publish a new immutable version, reratify changed artifacts, reconcile obligations, and resume only through the Gate.
- **Resource ceiling:** Opportunity budget, Composition Plan budget, Capability Genome envelopes, OMNIMORPH aggregate budget, evidence experiment budget, publication budget, evidence floor, graph-size bounds, and founder-attention ceiling.
- **Operating cost:** research, validation, compute, capability composition, evidence verification, content production, correction, platform APIs, customer delivery, reconciliation, compliance, and founder time.
- **Legal operator:** a named human or lawful entity, never UNIIMENTE, Foundry, OMNIMORPH, an agent swarm, or a synthetic persona.
- **Handoff:** qualified OpportunitySpec, complete route archive, immutable architecture hash, tribunal report, Composition Plan, Organ Manifest, simulation report, ratification record, Gate receipt, commercial closure receipts, and sealed or rejected Genome decision.
- **Replaceable:** models, strategy generators, renderers, runtimes, platform adapters, storage, and individual capability implementations may change behind stable contracts; the Constitution, evidence boundary, and external authority path may not be bypassed.
