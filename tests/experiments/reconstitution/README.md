# Cognitive reconstitution and inheritance

**Status: reversible simulation experiment.** [Founder directive, claim, and
handoff](https://github.com/dababiyoda/uniimente-kernel/issues/350).
The whole destination remains Body + Organs + Mind. This is a probe of one
missing mechanism: local interaction producing and retaining a useful reasoning
arrangement. Its inputs are synthetic. It imports no GREG runtime and creates no
authority.

## Scoring and comparators fixed before the first run

1. Start with a valid proof and a live preferred provider. Withdraw one source
   and remove a different provider together. The evaluator supplies the correct
   answers independently of the network. On every tick: never publish a proof
   with revoked ancestry, keep the unrelated conclusion, and keep the
   source-dependent conclusion absent. Restore the supported decision within six
   ticks with a different, multi-operator proof. Score the frozen-edge control
   using the same operators, messages, and initial state.
2. Against the same inputs, run a central adaptive fixed-point evaluator that
   retains unaffected proofs and can use every surviving rule. Score correctness,
   rounds and rule evaluations, counting rewiring separately. One round is a
   logical synchronization step, not a wall-clock comparison. A frozen-edge win
   isolates the interaction; comparative advantage requires a gain against
   adaptive central, with measurable costs and a matched budget.
3. Export only producer role preference per consumer role and input position
   from the recovered decision's support. Compare that preference with a cold
   start on a different authored domain and dependency shape at the same
   six-tick budget. Score first correct answer, correctness of all externally
   scored conclusions, total rule checks, and changed connections. Report
   acquisition work separately. A narrow transfer win requires reduced work or
   rewiring and no worse correctness or first-answer round. This second fixture
   is exposed to the author, so independent withheld transfer remains open.

Keep passed, failed, tied, and missing evidence visible. Each route is selected
from valid matching local offers with deterministic tie breaking. The cases
cannot supply named routes or provide the oracle to local operators.

## Two strengthening passes

**Pass 1.** The founder-intent steward preserves the invention: locally
competent parts combine and pass forward a useful new arrangement. The
architect limits the experiment to the existing test surface so a failed idea
can be dropped without migration. Leaving the first transport lab as-is
preserves its parity result but cannot answer this question. An ordinary central
incremental evaluator is simpler and strong; a static arrangement is also a
useful control. Distinguish correctness, adaptation, comparative advantage,
and transfer so one gain cannot substitute for another. Main downside: easier
data can reward a scripted fallback. Operators instead receive typed ports
and observations, with role preferences extracted from a verified trace.

**Pass 2.** The adversarial reviewer challenged transport relabeled as
reasoning, a central chooser disguised as a broker, and memorized transfer.
Require evidence lineage, actual local binding changes, and a role-only
capsule without first-case identifiers or answers. The maintainability lens
keeps the evaluator, finite budget, and trace inspectable; the evidence and
welfare lens confines the probe to synthetic data and retains every losing
arm. Residual dissent: on small positive-rule problems a central evaluator can
match or beat the approach, and a known second fixture can flatter the
preference. Raise neither to a novelty claim. Resolve with an independently
withheld changed-domain suite and an equal-budget, maintenance-aware comparison.
**Disposition: EXPERIMENT.** The task issue holds the owner and handoff. Stop
pursuing an active runtime path if a simple method wins on attributable benefit.
Rollback by discarding the experiment branch or reverting its commits while
keeping the outcome record.
