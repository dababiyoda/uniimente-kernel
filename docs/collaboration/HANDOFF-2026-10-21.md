## 7. Known residuals and cautions

- **Load-sensitive tests:** the cognition SIGKILL and timeout tests are load-sensitive. A failure in the full suite must be re-run in isolation before it is called a flake. After one re-run, a second failure is real.
- **Confinement is Linux-only.** Landlock confinement needs ABI ≥ 3 for workers and ABI ≥ 6 for signal and socket scoping. Other hosts skip those tests, and a skip is not a pass.
- **Run-only defect:** the acceptance harness can fail a run on a cited test that only the full run exposes, as `KeyError 'checks'` did at acdd3c0. Read the run, not only `check`.
- **Safeguard blocks:** when the model provider's safeguards block a test corpus, record that as the gap's dependency. Do not reword the corpus to get around them.
