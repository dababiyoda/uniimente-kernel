## The actual invention

The invention is not the candidate shapes. It is the closed institutional
learning transaction:

1. an authorized MissionContract binds the objective, authority references,
   resources, evidence, risk, closure and geometry;
2. OMNIMORPH later emits materially different, content-bound organizational
   hypotheses without authority;
3. candidates execute under identical constraints through the canonical
   durable substrate;
4. independent evaluation preserves dissent and verifies closure;
5. an executed TopologyEpisode records causal performance, including losers;
6. only repeated executed evidence may promote a genome from hypothesis to
   reusable institutional knowledge.

If one static form wins almost universally, the compiler simplifies around it.
If dynamic forms tie while adding complexity, they lose. If different forms win
for different geometries, the compiler thesis survives. If none adds a new
capability, the organizational layer is killed and the evidence remains.
