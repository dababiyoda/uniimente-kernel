## Adoption sequence and acceptance

1. Review kernel #193 and its exact validation; adopt only through authorized merge.
2. Publish the prepared entry pointer in existing Discussion #89 when authenticated.
3. Review consumer diffs and pins, adopt kernel before consumer workflows. After a
   squash/rebase, retain the pinned source or repin to the adopted immutable commit.
4. Ask each active product worker to acknowledge the source pin, actual session,
   task, files/interfaces, current base/head and receiver. Do not mutate its branch
   or infer acknowledgment from a coordination comment.
5. Run one actual new/resumed Claude session in each client environment. Confirm
   loaded entry instructions, source access, live claim split and receiver resume.
   Sandbox model rehearsal is separately labeled in VALIDATION.md.
6. Observe the optional workflow on the adopted revision before any ruleset change.
   Check protections and status names; no settings changes are included here.
7. Measure the first five completed coordinated PRs: duplicate-work incidents,
   stale-base rework, successful handoffs, time to correct receiver action and
   founder interventions. Baseline is NOT_MEASURED; do not invent benefit metrics.
