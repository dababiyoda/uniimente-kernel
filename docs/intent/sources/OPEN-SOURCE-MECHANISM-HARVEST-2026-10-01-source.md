## Executable interpretation

The intended effect is **maximum lawful reuse before original construction** while completing the currently achievable GREG / UNIIMENTE machine.

During development, open-source repositories, public technical information, standards, papers, examples, and maintained free software are construction feedstock. Search them before recreating known mechanisms. Reuse may take one of five forms:

1. **DISCOVER** — inspect an educational/index repository to learn mechanism vocabulary, algorithms, data structures, failure modes, and alternatives without importing code.
2. **DEPEND** — use a maintained package or service behind a replaceable adapter when that is the smallest reliable path.
3. **VENDOR-SLICE** — copy/adapt a narrow source slice into UNIIMENTE only when the license permits it, provenance/notices are retained, tests are added, and carrying the full dependency would be worse.
4. **FORK/SUBTREE** — retain a coherent upstream subsystem only when its architecture, license, maintenance burden, and update path justify the coupling.
5. **RECOMBINE** — when no existing mechanism closes the CapabilityDeficit, extract causal primitives from multiple sources, mutate them using Mechanism Recombination Foundry, and build only the residual novel capability.

"Copy and paste" never means ignoring licenses, attribution, patents, security, privacy, terms, model/data licenses, transitive dependencies, or upstream maintenance. Educational code is not production code merely because it runs. Whole repositories are not pasted into the active tree merely because they are useful references.
